# SI-SDI multi-modal fusion framework for IAV pandemic-potential warning

This repository contains the analysis scripts used for the manuscript:

**Pandemic potential warning of avian IAV based on multi-modal fusion of viral genome and spatial transmissibility**

The workflow implements an alignment-free genomic Similarity Index (SI), a geospatial Spatial Dissemination Index (SDI), SI-SDI multi-modal fusion risk stratification, and the H5N1-focused Pandemic Risk Index (PRI).

## Contents

### Data curation and preprocessing

- `rename_98787.py`: strain-name normalization for downstream sequence matching.
- `clean_dates_98787data.py`: collection-date standardization and decimal-year generation.
- `prepare_5001_fasta.py`: representative FASTA preparation for phylogenetic benchmarking.

### SI calculation

- `calc_counting.py`: alignment-free dinucleotide and codon-pair feature extraction.
- `calc_distance_PB2.py`: segment-level distance matrix calculation.
- `calc_SI.py`: PCA-weighted SI calculation and HDF5 output generation.

### SDI and SI-SDI fusion

- `geo_13.py`: offline geographic coordinate dictionary used by the spatial workflow.
- `calc_vrp.py`: H3-grid spatial dissemination scoring.
- `calc_fig6_evolution_full.py`: compositional relative-entropy metrics for independent validation.
- `cal_fig6_SI_SDI_csv.py`: SI-SDI master source table for risk-quadrant analysis.

### Figures and supplementary source tables

- `fig2.py`: global spatiotemporal and metadata landscape.
- `fig3.py`: alignment-free compositional feature analysis.
- `fig4_step_capped_downsample.py`: capped subtype-year downsampling for manifold reconstruction.
- `fig4A-H&Supplementary_fig3.py`: SI benchmarking, UMAP and phylogenetic-topology visualization.
- `fig5&Supplementary_fig4_6.py`: SDI spatial vectorization maps and related supplementary figures.
- `Supplementary_fig2.py`: SI-SDI correlation analysis.
- `fig6.py`: SI-SDI multi-modal fusion risk-quadrant figure.
- `fig7_h5n1_PRI.py`: H5N1-focused PRI analysis, Figure 7 and Figure 7 source tables.
- `build_supplementary_table4_efficiency.py`: computational-efficiency source table.

## Environment

Python 3.10 or later is recommended.

Install the core dependencies with:

```bash
pip install -r requirements.txt
```

Some geospatial plotting functions require a working Cartopy/GEOS/PROJ stack. On conda-based systems, the geospatial packages are often easier to install with:

```bash
conda install -c conda-forge cartopy shapely pyproj
```

## Data availability and restrictions

Raw IAV genomic sequences and metadata were obtained from NCBI GenBank and GISAID. Raw sequence files and GISAID submitter acknowledgements are not redistributed here and should be obtained from the original databases under their respective access terms.

The manuscript supplementary files provide processed source data where redistribution is permitted, including SI, SDI and PRI summaries used in the final figures.

## Reproducibility workflow

The main workflow is:

```bash
python rename_98787.py
python clean_dates_98787data.py
python calc_counting.py
python calc_distance_PB2.py
python calc_SI.py
python calc_vrp.py
python calc_fig6_evolution_full.py
python cal_fig6_SI_SDI_csv.py
```

The figure workflow is:

```bash
python fig2.py
python fig3.py
python fig4_step_capped_downsample.py
python fig4A-H&Supplementary_fig3.py
python fig5&Supplementary_fig4_6.py
python Supplementary_fig2.py
python fig6.py
python fig7_h5n1_PRI.py
python build_supplementary_table4_efficiency.py
```

Several scripts retain the original local path constants used during manuscript preparation. Before running the workflow on another machine, edit the input and output paths near the top of each script, or mirror the same directory structure locally.

## Notes

- Large raw and intermediate data tables are intentionally not included in this code package.
- Paths should be configured before runtime reproduction.
- The final Figure 7 source tables are generated by `fig7_h5n1_PRI.py`.
